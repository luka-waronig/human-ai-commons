# WaterToC ICCS 2026

Conference model and analysis for [Emergent Spatial Traps in the Coevolutionary Commons: Human-AI Cooperation Under Environmental Feedback](https://doi.org/10.1007/978-3-032-29909-3_8).

- [Installation and usage](docs/usage.md)
- [Model equations and analysis](docs/model-and-analysis.md)

Run commands from this folder:

```bash
python -m pip install --require-hashes -r requirements.txt
python -m pytest -q
solara run server.py
```
